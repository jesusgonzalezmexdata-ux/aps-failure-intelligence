Which Scania trucks should go to the workshop?

A missed air-pressure-system failure costs 500; an unnecessary check costs 10. The model turns 170 anonymous truck readings into a check / no-check rule tuned to those costs.

How the decision was made

  1. Byte-verified data; the official test set is sealed in code.
  2. Baseline, candidates and a 12-configuration tuning budget, all fixed before results existed.
  3. Decision threshold chosen on training out-of-fold scores only.
  4. One evaluation on the test set, then stress tests, monitoring and recalibration.

What it does not claim

  • Classifies current readings; it does not forecast when a failure will happen.
  • Costs are the challenge's units, not money.
  • Readings are anonymous, so drivers show which readings matter, not why.
