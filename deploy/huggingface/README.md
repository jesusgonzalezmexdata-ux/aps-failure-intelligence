# APS failure triage

A missed air-pressure-system failure costs 500; an unnecessary check costs 10. The model turns 170 anonymous truck readings into a check / no-check rule tuned to those costs.

**Result:** −94 % official cost against no triage (Scania's test set, 16,000 trucks, evaluated once).
